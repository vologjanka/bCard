# Урок 2 — комментарии для преподавателя

Этот файл дублирует **подробные пояснения** к коду проекта «визитка»: что делает каждый фрагмент, зачем он нужен и как связан с вёрсткой. В исходниках (`src/`) оставлены **короткие однострочные комментарии** для учеников.

---

## `src/main.tsx`

- **`createRoot(document.getElementById('root')!)`** — точка монтирования React: находится элемент `#root` в `index.html`, в него рендерится всё приложение. Восклицательный знак — утверждение для TypeScript, что элемент точно есть.
- **`StrictMode`** — в режиме разработки React дополнительно проверяет компоненты (устаревшие API, побочные эффекты). На продакшен-сборку не влияет по размеру заметно; помогает учиться безопасным паттернам.
- **Импорт `./index.css`** — глобальные стили и шрифты подключаются один раз до `App`.

## `src/App.tsx`

### Импорты

- **`useRef`** — хранит ссылку на DOM-узел (колонку с фото), чтобы прочитать его высоту.
- **`useState`** — хранит число `photoHeight` (высота колонки с фото в пикселях).
- **`useEffect`** — подписка на изменение размеров после монтирования и очистка при размонтировании.
- **`CSSProperties`** — тип для объекта стилей; используется при передаче CSS-переменной `--photo-height` в React (`style={...}`).

### `photoColumnRef` и `photoHeight`

- Колонка справа с фото имеет **естественную высоту** (от картинки и паддингов). Левая колонка должна иметь **ту же суммарную высоту**, чтобы блоки «ФИО» и «Обо мне» делили её в пропорции **30% / 70%** (через `grid-template-rows: 3fr 7fr` в CSS).
- Без измерения высоты левая колонка не «знает», какой высоты правая колонка — пропорции по сетке работали бы относительно своего контента, а не относительно фото.

### `useEffect` и `ResizeObserver`

- **`getBoundingClientRect().height`** — фактическая высота блока с фото в пикселях.
- **`ResizeObserver`** — браузерное API: вызывает колбэк, когда размер наблюдаемого элемента меняется (окно перетянули, сменилась ориентация, подгрузилась картинка и т.д.).
- **`observer.disconnect()` в cleanup** — отписываемся, чтобы не было утечек и лишних обновлений после ухода со страницы.

### `infoColumnStyle`

- В React можно передать **кастомные CSS-свойства** через объект `style`: ключ `'--photo-height'` попадает на элемент `.info-column`.
- В `App.css` для `.info-column` задано `height: var(--photo-height, auto)`: если переменная есть — высота совпадает с колонкой фото; если ещё не измерили (`0`), можно показать `auto`, чтобы не было скачка.

### Разметка

- **`main.page`** — корневой контейнер страницы с тёмным фоном из `App.css`.
- **`header.topBar` + `nav.menu`** — верхнее меню-заглушка с якорными ссылками на будущие секции (`#home`, `#hobbies` …).
- **`section#home.heroSection`** — главный блок «героя» визитки.
- **`content-row`** — flex-ряд: слева текст, справа фото.
- **`info-column`** — сетка из двух строк (`FullName`, `AboutMe`).
- **`photo-column`** с **`ref={photoColumnRef}`** — сюда навешан ref для измерения высоты.

## `src/App.css`

### `.page`

- Локальные **CSS-переменные** (`--bg`, `--panel`, `--text-primary`, …) позволяют держать палитру в одном месте; при желании тему можно вынести или переключать.
- **`min-height: 100vh`** — страница тянется минимум на высоту окна.
- **`display: flex; flex-direction: column`** — вертикальный столбец: сверху меню/контент.
- **`linear-gradient`** — фон «Apple dark» стилем.

### `.menu`, `.menu a`

- **`backdrop-filter: blur`** — лёгкое матирование панели меню.
- **`transition`** — плавная смена фона/цвета при `:hover`.
- **`:focus-visible`** — заметный контур для тех, кто переходит по Tab (доступность).

### `.content-row`

- **`display: flex`** — два столбца в ряд на широком экране.
- **`align-items: flex-start`** — выравнивание по верхнему краю (важно для согласования колонок).

### `.info-column`

- **`display: grid`** + **`grid-template-rows: 3fr 7fr`** — первая строка (ФИО) занимает 3 доли, вторая (Обо мне) — 7 долей **общей высоты** сетки.
- **`height: var(--photo-height, auto)`** — высота сетки равна измеренной высоте колонки с фото (синхронизация из `App.tsx`).
- **`z-index`** — при необходимости управлять наслоением; здесь текстовая колонка ниже/на одном уровне с фото по задумке макета.

### `.photo-column`

- **`flex: 0 0 420px`** и **`width: 420px`** — фиксированная ширина колонки под размер фото (в связке с ограничением ширины самой картинки в модуле).

### `@media (max-width: 900px)`

- **`flex-direction: column`** — на узком экране колонки идут друг под другом.
- Ширины **`100%` / `max-width: 720px`** — читаемость на телефоне.

## `src/index.css`

- **`@import` Google Fonts** — подключение **Playfair Display** (заголовки) и **Source Sans 3** (основной текст).
- **`:root`** — глобальные переменные шаблона Vite; часть используется модулями компонентов через `var(--heading)` и т.д.
- **`@media (prefers-color-scheme: dark)`** — автоматическая тёмная палитра для корня документа по системным настройкам (часть переменных может пересекаться с явной тёмной темой в `App.css`).
- **`#root`** — растягивание приложения на всю ширину (`width: 100%`), flex-колонка для вложенного `App`.
- **`body { margin: 0 }`** — убираем отступ браузера по умолчанию.
- **`h1`, `h2`, `p`, `code`** — базовая типографика шаблона; компонентные модули могут переопределять размеры локально.

## `src/components/ProfilePhoto.tsx` и `ProfilePhoto.module.css`

- **`import.meta.env.BASE_URL`** — базовый путь Vite; на GitHub Pages часто нужен префикс репозитория. Сборка подставляет правильный префикс, чтобы `myfoto.jpg` из `public/` открывался по верному URL.
- **`.photoCard`** — обёртка с фоном и тенью.
- **`.photo`**: **`display: block`** убирает типичный нижний «зазор» у inline-`img`; **`width: min(100%, 420px)`** — не шире 420px, но сжимается на узком экране; **`height: auto`** сохраняет пропорции.

---

## `src/components/FullName.tsx` и `FullName.module.css`

- Семантика: **`h1`** — главный заголовок страницы; **`p.subtitle`** — вторичная строка (профессия, город).
- **`.fullName`**: **`height: 100%`** заполняет первую строку сетки `3fr`; **`box-sizing: border-box`** — padding входит внутрь высоты, чтобы не ломать пропорции.
- **`.title`**: **`clamp(34px, 6vw, 56px)`** — плавное масштабирование между минимумом и максимумом от ширины viewport.

---

## `src/components/AboutMe.tsx` и `AboutMe.module.css`

- **`aria-label="Обо мне"`** на `section` — краткая метка для скринридеров.
- **`.aboutMe`**: как и у ФИО, **`height: 100%`** для второй строки сетки `7fr`.
- **`::before`** — декоративная линия под заголовком (псевдоэлемент позиционируется относительно `position: relative` у `.aboutMe`).
- **`.text`**: **`line-height: 1.6`** улучшает читаемость абзацев.
