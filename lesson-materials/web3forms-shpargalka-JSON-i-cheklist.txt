ШПАРГАЛКА НА ДОСКУ — поля JSON для Web3Forms (POST на api.web3forms.com/submit)
Урок: форма «Написать мне» в React + Vite
================================================================================

Адрес запроса (для справки на доске):
  POST  https://api.web3forms.com/submit
  Заголовок:  Content-Type: application/json

Таблица полей в JSON.stringify({ ... })  —  как в нашем ContactSection.tsx

+------------------+----------+--------------------------------------------------+
| Поле в JSON      | Обяз.? | Что кладём                                       |
+------------------+----------+--------------------------------------------------+
| access_key       | да      | Ключ из .env: import.meta.env.VITE_WEB3FORMS_... |
| subject          | нет*    | Тема письма (строка), напр. «Сообщение с визитки» |
| name             | да**    | Имя из поля формы (name.trim())                  |
| email            | да**    | Email из поля формы (email.trim())             |
| message          | да**    | Текст сообщения (message.trim())                |
+------------------+----------+--------------------------------------------------+

* subject часто желателен, чтобы в почте было понятно, откуда письмо.
** Для курса мы всё равно проверяем поля сами до fetch; для API смотрите
   актуальную таблицу на https://web3forms.com

Короткая «одна строка для памяти» на доску:
  { access_key, subject, name, email, message }

================================================================================
ЧЕКЛИСТ УЧЕНИКА / ПРЕПОДАВАТЕЛЯ  (после урока или перед демо)
================================================================================

[ ] 1. Файл .env в папке my-app (рядом с package.json), одна строка без кавычек:
        VITE_WEB3FORMS_ACCESS_KEY=вставить_ключ_с_web3forms.com

[ ] 2. Перезапуск dev-сервера:
        остановить терминал (Ctrl+C) → снова npm run dev
        (иначе Vite может не увидеть новую переменную)

[ ] 3. Тест в браузере:
        заполнить имя, email, сообщение корректно → «Отправить»
        дождаться «Отправляем…» и зелёного успеха или текста ошибки

[ ] 4. Почта:
        открыть ВХОДЯЩИЕ на том ящике, который указывали при создании ключа
        заглянуть в папку «СПАМ» / «Нежелательная почта»
        подождать 1–3 минуты при задержке

[ ] 5. Git:
        git status — файла .env НЕТ среди файлов на коммит
