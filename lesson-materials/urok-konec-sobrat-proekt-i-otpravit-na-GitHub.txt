================================================================================
КОНЕЦ УРОКА: собрать проект и отправить на GitHub (+ сайт на GitHub Pages)
Для учеников и преподавателя. Windows, PowerShell. Репозиторий: корень bCard.
================================================================================

РЕПЛИКИ ПРЕПОДАВАТЕЛЯ (в конец урока)
-------------------------------------
«Сайт у нас уже “умеет” отправлять форму. Последний шаг цивилизации — сохранить
код в GitHub и обновить страницу в интернете, чтобы родители могли открыть
ссылку.»

«Два разных действия: (1) git push — кладём ИСХОДНИКИ в ветку main;
(2) npm run deploy — кладём СБОРКУ в ветку gh-pages, откуда GitHub Pages
показывает сайт.»

«Файл .env с ключом НЕ уходит в Git — он только на компьютере. Ключ уже
“вшит” в JS при сборке, если деплой делаете с машины, где есть .env.»

================================================================================
ЧАСТЬ A. Проверить, что проект собирается (папка my-app)
================================================================================
Открыть PowerShell.

  cd C:\js\react\bCard\my-app
  npm run build

Ожидаемо: в конце “built” без ошибок; появляется папка dist (её не коммитят —
она в .gitignore).

Если ошибка — читать красный текст в терминале, исправить код, снова
npm run build.

Дополнительно (по желанию):

  npm run lint

================================================================================
ЧАСТЬ B. Сохранить код на GitHub (ветка main) — из КОРНЯ репозитория
================================================================================
Корень — папка, где лежит скрытая папка .git (у вас обычно C:\js\react\bCard).

  cd C:\js\react\bCard
  git status

Проверка: в списке НЕ должно быть .env (файл в my-app/.gitignore).

  git add .
  git commit -m "Урок: Web3Forms, форма обратной связи"
  git push origin main

Если ветка называется master — замените main на master.

Если git просит логин — использовать способ, который настроен в классе
(GitHub Desktop, токен, учётная запись).

================================================================================
ЧАСТЬ C. Опубликовать САЙТ на GitHub Pages (обновить gh-pages)
================================================================================
Сайт уже привязан к Pages с ветки gh-pages — после правок нужно снова деплой.

  cd C:\js\react\bCard\my-app
  npm run deploy

Внутри: сначала npm run build, затем выкладка папки dist в ветку gh-pages.

Подождать 1–3 минуты и открыть в браузере (подставьте свой ник и имя репо):

  https://ВАШ_НИК.github.io/bCard/

Жёсткое обновление страницы: Ctrl+F5.

================================================================================
ЧАСТЬ D. Если GitHub Pages ещё ни разу не включали (только для нового репо)
================================================================================
На github.com: Settings → Pages → Source: Deploy from a branch →
Branch: gh-pages, folder: / (root) → Save.
