================================================================================
ВСТАВКА 02 — два новых useState (ожидание и ошибка сети/API)
================================================================================

ГДЕ: внутри function ContactSection() сразу ПОСЛЕ строки:
     const [isSuccess, setIsSuccess] = useState(false)

ЧТО СДЕЛАТЬ: ВСТАВИТЬ две следующие переменные состояния (весь блок ниже).

ЗА ЧТО ОТВЕЧАЕТ:
• isSubmitting — true, пока ждём ответ сервера; кнопку и поля можно блокировать.
• submitError — строка с ошибкой «дороги» до сервиса или ответа сервиса;
  это НЕ errors.name / errors.email (это про поля формы).


----- СКОПИРУЙТЕ ВЕСЬ БЛОК НИЖЕ -----

  /** [УЧЕБА: Урок 6] true = ждём ответ API; кнопку блокируем, чтобы не отправить дважды. */
  const [isSubmitting, setIsSubmitting] = useState(false)

  /** [УЧЕБА: Урок 6] Текст ошибки сети / сервиса (не путать с errors — это про поля формы). */
  const [submitError, setSubmitError] = useState('')
