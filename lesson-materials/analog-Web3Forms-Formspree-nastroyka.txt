================================================================================
Аналог Web3Forms: Formspree (https://formspree.io)
Подробная настройка «секрета» формы для урока (Vite + React)
================================================================================

ПОЧЕМУ ИМЕННО FORMSPREE
-----------------------
• Как и Web3Forms: не нужен свой сервер с PHP — отправка с фронта по HTTPS.
• Понятный личный кабинет, бесплатный тариф с лимитами (актуальные лимиты
  смотрите на сайте Formspree).
• «Секрет» формы — это URL вида https://formspree.io/f/XXXXXXXX (его не
  светят в открытом GitHub — кладут в .env).

ВАЖНО ПРО СЛОВА
---------------
У Web3Forms секрет называют Access Key (строка в JSON access_key).
У Formspree чаще показывают готовый ENDPOINT — полную ссылку с /f/ и кодом.
Смысл тот же: «по этому адресу сервис понимает, что письмо от ВАШЕЙ формы».

================================================================================
ШАГ 1. Открыть сайт и войти
================================================================================
1. Браузер → адресная строка: https://formspree.io
2. Sign up (регистрация) или Log in (вход), если аккаунт уже есть.
3. Для класса удобен один аккаунт преподавателя / школы — по правилам курса.

Реплика для детей:
«Сначала “представляемся” почтальону — как взять пропуск в музей.»

================================================================================
ШАГ 2. Создать новую форму
================================================================================
1. Войти в Dashboard (личный кабинет).
2. Найти кнопку вроде: New Form / Create form / + (зависит от версии UI).
3. Заполнить:
   • Имя формы — любое для себя (например «Визитка урок 6»).
   • Email получателя — КУДА приходят письма с сайта (подтвердите почту,
     если сервис попросит).

Реплика:
«Email здесь — это адрес на конверте “кому доставить”, не пароль от Formspree.»

================================================================================
ШАГ 3. ГДЕ «КЛЮЧ» — что скопировать
================================================================================
После создания формы Formspree показывает интеграцию. Нужно скопировать ОДИН
из вариантов (что именно покажут — зависит от экрана):

Вариант A (самый частый):
  Полный URL:
  https://formspree.io/f/abcdwxyz
  (буквы/цифры после /f/ — уникальный id формы)

Вариант B:
  Только id: abcdwxyz
  Тогда в коде собирают полный URL сами: https://formspree.io/f/ + id

Кнопка «Copy» рядом с endpoint — лучше копировать ей, не выделять глазами.

Реплика:
«Это не “пароль от почты”. Это “номер ячейки” у посредника Formspree.»

================================================================================
ШАГ 4. Положить секрет в .env (Vite)
================================================================================
В папке my-app (рядом с package.json) создать или отредактировать файл .env

Рекомендуемая переменная (полный URL — проще для fetch):

  VITE_FORMSPREE_ENDPOINT=https://formspree.io/f/ВАШ_КОД

Если хотите хранить только id:

  VITE_FORMSPREE_FORM_ID=ВАШ_КОД

Тогда в коде URL собирают: `https://formspree.io/f/${id}`

Правила Vite:
• Имя переменной начинается с VITE_ — иначе Vite не отдаст её в браузер.
• После изменения .env ОБЯЗАТЕЛЬНО перезапустить: npm run dev

Файл .env в .gitignore — НЕ коммитить в GitHub.

Шаблон для репозитория (можно коммитить): .env.example

  VITE_FORMSPREE_ENDPOINT=

================================================================================
ШАГ 5. Типы для TypeScript (vite-env.d.ts)
================================================================================
В src/vite-env.d.ts добавить в ImportMetaEnv, например:

  readonly VITE_FORMSPREE_ENDPOINT?: string

(или VITE_FORMSPREE_FORM_ID — как выбрали.)

================================================================================
ШАГ 6. Отправка из React (идея, отличие от Web3Forms)
================================================================================
После локальной валидации полей:

  const endpoint = import.meta.env.VITE_FORMSPREE_ENDPOINT?.trim()
  if (!endpoint) { /* показать: настройте .env */ return }

  const response = await fetch(endpoint, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Accept: 'application/json',
    },
    body: JSON.stringify({
      name: name.trim(),
      email: email.trim(),
      message: message.trim(),
    }),
  })

Дальше разбор response (статус, тело) — по актуальной документации Formspree
(иногда нужны дополнительные поля или заголовки — сверяйтесь с сайтом).

Реплика:
«Web3Forms просил access_key внутри JSON. Formspree чаще говорит: “шлите POST
на ВАШ личный адрес формы” — секрет уже спрятан в самом URL.»

================================================================================
ШАГ 7. Проверка
================================================================================
1. Локально: заполнить форму → Отправить.
2. Проверить почту получателя и папку «Спам».
3. В кабинете Formspree иногда видно журнал отправок (зависит от тарифа).
